# サイト情報
- サイト名: {{SITE_NAME}}
- 運営者名: {{SITE_OPERATOR_NAME}}
- 連絡先: {{SITE_CONTACT_EMAIL}}
- 運営開始日: {{SITE_LAUNCH_DATE}}
- ジャンル: {{SITE_GENRE}}

# 出力形式
以下の項目をMarkdownの表形式でまとめ、その下に3〜5行程度の簡単な自己紹介文（このサイトを運営する動機や専門分野）を追加すること。

| 項目 | 内容 |
|---|---|
| サイト名 | {{SITE_NAME}} |
| 運営者 | {{SITE_OPERATOR_NAME}} |
| 運営開始日 | {{SITE_LAUNCH_DATE}} |
| 連絡先 | {{SITE_CONTACT_EMAIL}}（またはお問い合わせページへのリンク） |
| サイトの目的 | {{SITE_GENRE}}に関する情報発信 |

# 注意事項
- 実在しない資格・経歴・実績を創作しないこと（不明な項目は空欄のままにするか、システム側で後から手動入力する前提のプレースホルダーにする）
- 誇張表現は避ける
